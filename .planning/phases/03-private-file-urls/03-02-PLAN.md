<task type="auto">
  <name>Task 1: Create FileService with store, signedUrl, and delete methods</name>
  <files>wave/src/Services/FileService.php</files>
  <action>
  Create `wave/src/Services/FileService.php`. Follow the existing service pattern from PlanChangeResolver — injectable class with focused methods.

  **Constructor:** No dependencies needed — uses facades.

  **Methods:**

  `store(UploadedFile $file, User $user, ?Organization $organization = null, string $directory = '', FileAccessLevel $accessLevel = FileAccessLevel::Private, ?Model $fileable = null): File`
  - Generate a UUID for the filename: `$uuid = (string) Str::uuid()`
  - Build path: `$directory . '/' . $uuid . '.' . $file->getClientOriginalExtension()` (trim leading slash)
  - Store the file on the `local` disk: `Storage::disk('local')->putFileAs(dirname($path), $file, basename($path))`
  - Create File record with all metadata: uuid (new Str::uuid for the record), organization_id from $organization, uploaded_by_user_id from $user, disk, path, original_name from $file->getClientOriginalName(), mime_type from $file->getMimeType(), size_bytes from $file->getSize(), access_level, metadata null
  - If $fileable is provided, set fileable_type and fileable_id
  - Return the created File model

  `storeFromContent(string $content, string $filename, string $mimeType, User $user, ?Organization $organization = null, string $directory = '', FileAccessLevel $accessLevel = FileAccessLevel::Private, ?Model $fileable = null): File`
  - Same as store() but accepts raw content (for base64-decoded avatar images, processed images, etc.)
  - Generate UUID-based path like store()
  - Store with `Storage::disk('local')->put($path, $content)`
  - Calculate size_bytes with `strlen($content)`
  - Create File record and return it

  `signedUrl(File $file, int $expirationMinutes = 30): string`
  - Generate a temporary signed route: `URL::temporarySignedRoute('files.download', now()->addMinutes($expirationMinutes), ['file' => $file->uuid])`
  - Return the signed URL string

  `delete(File $file): bool`
  - Delete the file from disk: `Storage::disk($file->disk)->delete($file->path)`
  - Delete the File record: `$file->delete()`
  - Return true on success

  `exists(File $file): bool`
  - Check if file exists on disk: `Storage::disk($file->disk)->exists($file->path)`

  All methods should have explicit return type declarations. Use `Illuminate\Http\UploadedFile` for the UploadedFile type.
  </action>

<task type="auto">
  <name>Task 2: Create FileDownloadController and register signed download route</name>
  <files>wave/src/Http/Controllers/FileDownloadController.php, wave/routes/web.php</files>
  <action>
  **FileDownloadController** (`wave/src/Http/Controllers/FileDownloadController.php`):
  Create a single-action controller (invokable) following Laravel convention.

  `__invoke(Request $request, string $file)`:
  - Look up the File by UUID: `$fileRecord = File::where('uuid', $file)->firstOrFail()` (use `firstOrFail` so missing files return 404)
  - Authorize access using the FilePolicy: `$this->authorize('download', $fileRecord)`
  - Check file exists on disk: if not, abort(404)
  - Return the file as a download response: `Storage::disk($fileRecord->disk)->download($fileRecord->path, $fileRecord->original_name)`

  The controller should extend `Illuminate\Routing\Controller` (or use no base class — check existing controller patterns in `wave/src/Http/Controllers/`). Use `Gate` or `$this->authorize()` for authorization.

  **Route registration** (`wave/routes/web.php`):
  Add a named route for file downloads. Place it with the existing route definitions.

  ```php
  Route::get('/files/{file}/download', \Wave\Http\Controllers\FileDownloadController::class)
      ->name('files.download')
      ->middleware(['auth', 'signed']);
  ```

  The `signed` middleware validates the URL signature automatically (built into Laravel). The `auth` middleware ensures the user is logged in before the FilePolicy check runs.

  Important: The `{file}` parameter is the UUID string, NOT route model binding. The controller resolves the File manually by UUID. This is because route model binding would use the `id` column by default, and we want to use `uuid` for external URLs.

  Do NOT add the route inside any middleware group that conflicts with the signed middleware. Check how existing routes are structured in `wave/routes/web.php` to ensure consistency.
  </action>
  <verify>Run `php artisan route:list --name=files.download` to confirm the route is registered with auth and signed middleware. Check that the route name resolves: `php artisan tinker --execute="echo route('files.download', ['file' => 'test-uuid']);"` — should output a URL (without signature, that's fine for verification).</verify>

     ```php
     $fileService = app(\Wave\Services\FileService::class);

     // Delete previous avatar file if exists
     $oldFile = auth()->user()->avatarFile;
     if ($oldFile) {
         $fileService->delete($oldFile);
     }

     $file = $fileService->storeFromContent(
         content: $encoded,
         filename: auth()->user()->username . '.png',
         mimeType: 'image/png',
         user: auth()->user(),
         directory: 'avatars',
         accessLevel: \App\Enums\FileAccessLevel::AppPublic,

     );
     ```

  <name>Task 2: Wire avatar display through signed URLs</name>
  <files>wave/src/User.php, app/Filament/Resources/Users/UserResource.php, app/Filament/Resources/Members/MemberResource.php</files>
  <action>
  **User model** (`wave/src/User.php`):

  1. Add `avatarFile()` morphOne relationship:
     ```php
     public function avatarFile(): MorphOne
     {
         return $this->morphOne(\Wave\File::class, 'fileable');
     }
     ```

  2. Replace the `avatar()` method. Only two cases -- UUID or default:
     ```php
     public function avatar(): string
     {
         if (empty($this->attributes['avatar'])) {
             return url('storage/demo/default.png');
         }

         $file = $this->avatarFile;
         if ($file) {
             return app(\Wave\Services\FileService::class)->signedUrl($file);
         }

         return url('storage/demo/default.png');
     }
     ```

  3. Add a scope for eager loading in list contexts (do NOT add to global `$with`):
     ```php
     public function scopeWithAvatarFile(Builder $query): Builder
     {
         return $query->with('avatarFile');
     }
     ```

  **Filament UserResource** (`app/Filament/Resources/Users/UserResource.php`):

  1. Form `FileUpload::make('avatar')`:
     - Add `->disk('local')->directory('avatars')`
     - Add `saveUploadedFileUsing()` callback that calls FileService::store(), creates File record with access_level=app_public and fileable pointing to the user, returns the File UUID
     - Add `loadStateFromRecordUsing()` to convert UUID back to displayable URL for form preview

  2. Table `ImageColumn::make('avatar')`:
     - Change to `->getStateUsing(fn ($record) => $record->avatar())` to get the signed URL
     - Keep `->circular()` and `->defaultImageUrl(url('storage/demo/default.png'))`

<task type="auto">
  <name>Task 1: Core file infrastructure tests</name>
  <files>tests/Feature/FileAccessTest.php</files>
  <action>
  Create `tests/Feature/FileAccessTest.php` using `php artisan make:test FileAccessTest --pest --no-interaction`.

  Follow existing test patterns from TenantScopingTest.php. Use Pest syntax with `describe()` blocks and `it()` tests.

  **Test group: File model and tenant scoping**

  `it('scopes files to tenant context')`:
  - Create two organizations with files
  - Set TenantContext to org A
  - Assert File::all() returns only org A's files
  - Set TenantContext to org B
  - Assert File::all() returns only org B's files

  `it('auto-fills organization_id from tenant context on create')`:
  - Set TenantContext to an org
  - Create a File without explicitly setting organization_id
  - Assert the File has the org's ID

  `it('allows files without organization for personal context')`:
  - Create a File with organization_id = null
  - Assert it exists and is accessible without tenant context

  **Test group: FileService store and signedUrl**

  `it('stores a file on the local disk and creates File record')`:
  - Create a fake UploadedFile: `UploadedFile::fake()->create('test.pdf', 100, 'application/pdf')`
  - Call `FileService::store($file, $user, $org, 'documents')`
  - Assert File record exists in DB with correct attributes
  - Assert file exists on disk: `Storage::disk('local')->assertExists($file->path)`

  `it('stores content from string and creates File record')`:
  - Call `FileService::storeFromContent('hello world', 'test.txt', 'text/plain', $user)`
  - Assert File record exists
  - Assert file content matches on disk

  `it('generates valid signed URL')`:
  - Create a File via factory
  - Call `FileService::signedUrl($file)`
  - Assert URL contains the file UUID
  - Assert URL contains `signature` query parameter
  - Assert URL contains `expires` query parameter

  `it('deletes file from disk and database')`:
  - Store a file via FileService
  - Call `FileService::delete($file)`
  - Assert file does not exist on disk
  - Assert File record is gone from DB

  **Test group: FilePolicy authorization**

  `it('allows org member to download private org file')`:
  - Create org, add user as member, create file for org
  - Assert `Gate::forUser($user)->allows('download', $file)` is true

  `it('denies non-member from downloading private org file')`:
  - Create org with file, create separate user NOT in org
  - Assert `Gate::forUser($outsider)->denies('download', $file)` is true

  `it('allows any authenticated user to download app_public file')`:
  - Create app_public file (e.g., avatar)
  - Create a random user who is NOT in the file's org and NOT the uploader
  - Assert `Gate::forUser($randomUser)->allows('download', $file)` is true

  `it('allows uploader to download their personal file')`:
  - Create personal file (org_id = null) uploaded by user
  - Assert `Gate::forUser($uploader)->allows('download', $file)` is true

  `it('denies other users from downloading personal private file')`:
  - Create personal private file (org_id = null)
  - Create different user
  - Assert `Gate::forUser($otherUser)->denies('download', $file)` is true

  `it('allows only uploader to delete file')`:
  - Create file uploaded by user A
  - Assert user A can delete
  - Assert user B (even if in same org) cannot delete

  Use `Storage::fake('local')` in tests to avoid writing to real disk.
  </action>

<task type="auto">
  <name>Task 2: Download route and edge case tests</name>
  <files>tests/Feature/FileAccessTest.php</files>
  <action>
  Add more test groups to the existing `tests/Feature/FileAccessTest.php`.

  **Test group: Download route**

  `it('serves file via signed download URL')`:
  - Store a real file on fake disk via FileService
  - Generate signed URL via FileService::signedUrl()
  - Extract the path and query from the signed URL
  - Make a GET request as the file's uploader (authenticated)
  - Assert 200 response
  - Assert response has correct Content-Type or Content-Disposition header

  `it('returns 403 for expired signed URL')`:
  - Create a file and generate signed URL with very short expiration
  - Use `$this->travel(31)->minutes()` (or Carbon::setTestNow) to advance time past expiration
  - Make a GET request with the expired URL
  - Assert 403 response (Laravel's signed middleware returns 403 for invalid signatures)

  `it('returns 403 for tampered signed URL')`:
  - Generate a signed URL
  - Modify the signature parameter in the URL
  - Make a GET request
  - Assert 403 response

  `it('returns 403 when unauthorized user accesses private file')`:
  - Create a private org file
  - Generate valid signed URL
  - Make the request as a different user NOT in the org
  - Assert 403 response

  `it('returns 404 for non-existent file UUID')`:
  - Generate a signed URL with a fake UUID that doesn't exist in the database
  - Make a GET request
  - Assert 404 response

  `it('returns 404 when file record exists but disk file is missing')`:
  - Create a File record in DB but don't create the actual file on disk
  - Generate signed URL
  - Make request as authorized user
  - Assert 404 response

  **Test group: Cross-tenant isolation (integration)**

  `it('prevents cross-tenant file access via download route')`:
  - Create org A with user A and a private file
  - Create org B with user B
  - Generate signed URL for org A's file
  - Make request as user B (authenticated but wrong org)
  - Assert 403 response

  `it('allows cross-org access for app_public files via download route')`:
  - Create app_public file belonging to org A
  - Generate signed URL
  - Make request as user from org B
  - Assert 200 response (app_public files are accessible to any authenticated user)

  **Test group: FileService edge cases**

  `it('handles duplicate file paths by using UUID-based filenames')`:
  - Store two files with the same original name in the same directory
  - Assert both File records exist with different paths
  - Assert both files exist on disk

  `it('creates file with fileable relationship')`:
  - Store a file with fileable pointing to a User model
  - Assert `$file->fileable` returns the User instance
  - Assert `$user->morphOne(File::class, 'fileable')->first()` returns the file

  Use `Storage::fake('local')` for all tests. Use `$this->actingAs($user)` for authenticated requests.
  </action>
  <verify>Run `php artisan test --compact --filter=FileAccessTest` — all tests pass, including the new edge case tests.</verify>

  <name>Task 1: Create FileAccessLevel enum, File model, and migration</name>
  <files>app/Enums/FileAccessLevel.php, wave/src/File.php, database/migrations/2026_03_12_000001_create_files_table.php</files>
  <action>
  **FileAccessLevel enum** (`app/Enums/FileAccessLevel.php`):
  Follow AccountStatus enum convention. Two cases:
  - `Private = 'private'` — tenant-scoped authorization (org members or uploader only)
  - `AppPublic = 'app_public'` — any authenticated user can access (for avatars, shared resources)
  Add a `label(): string` method returning human-readable names.

  **File model** (`wave/src/File.php`):
  Place in `wave/src/` following ActivityLog/ApiKey convention. Use `BelongsToTenant` trait.

  Properties and config:
  - `$guarded = []`
  - Cast `access_level` to `FileAccessLevel` enum, `metadata` to `array`, `size_bytes` to `integer`
  - Auto-generate `uuid` in `creating` event using `Str::uuid()` (do NOT use HasUuids — keep integer PK for consistency)

  Relationships:
  - `organization(): BelongsTo` — provided by BelongsToTenant trait
  - `uploadedBy(): BelongsTo` — to User model via `uploaded_by_user_id`
  - `fileable(): MorphTo` — nullable polymorphic relation (what this file is attached to)

  Scopes:
  - `scopeForUser(Builder $query, User $user): Builder` — files uploaded by this user
  - `scopeAccessibleBy(Builder $query, User $user): Builder` — files the user can access (app_public files OR files in user's orgs OR files uploaded by user)

  Helper methods:
  - `isPrivate(): bool`
  - `isAppPublic(): bool`
  - `isOwnedBy(User $user): bool` — checks uploaded_by_user_id

  **Migration** (`database/migrations/2026_03_12_000001_create_files_table.php`):
  Anonymous class style. Columns:
  - `id` bigIncrements
  - `uuid` string, unique index
  - `organization_id` unsignedBigInteger, nullable, foreign key to organizations with nullOnDelete (matches tenant column convention from Phase 1)
  - `uploaded_by_user_id` unsignedBigInteger, foreign key to users with cascadeOnDelete
  - `fileable_type` string, nullable
  - `fileable_id` unsignedBigInteger, nullable
  - `disk` string, default `'local'`
  - `path` string
  - `original_name` string
  - `mime_type` string
  - `size_bytes` unsignedBigInteger
  - `access_level` string, default `'private'`
  - `metadata` json, nullable
  - `timestamps`

  Indexes:
  - Composite index on `fileable_type` + `fileable_id`
  - Composite unique index on `disk` + `path`
  - Index on `uploaded_by_user_id`
  - Index on `organization_id`
  </action>

<task type="auto">
  <name>Task 2: Create FileFactory and FilePolicy</name>
  <files>database/factories/FileFactory.php, app/Policies/FilePolicy.php</files>
  <action>
  **FileFactory** (`database/factories/FileFactory.php`):
  Use `php artisan make:factory FileFactory --no-interaction` then customize.
  Point the factory at `Wave\File` model.

  Default definition:
  - `uuid` → `fake()->uuid()`
  - `organization_id` → `Organization::factory()` (nullable in states)
  - `uploaded_by_user_id` → `User::factory()`
  - `disk` → `'local'`
  - `path` → `'files/' . fake()->uuid() . '.txt'`
  - `original_name` → `fake()->word() . '.txt'`
  - `mime_type` → `'text/plain'`
  - `size_bytes` → `fake()->numberBetween(100, 1000000)`
  - `access_level` → `FileAccessLevel::Private`
  - `metadata` → `null`

  States:
  - `appPublic()` — sets `access_level` to `FileAccessLevel::AppPublic`
  - `personal()` — sets `organization_id` to `null` (no tenant, personal file)
  - `forUser(User $user)` — sets `uploaded_by_user_id` to `$user->id`
  - `forOrganization(Organization $org)` — sets `organization_id` to `$org->id`

  **FilePolicy** (`app/Policies/FilePolicy.php`):
  Use `php artisan make:policy FilePolicy --model=File --no-interaction` (note: model is `Wave\File`). If the artisan command does not support the Wave namespace, create manually.

  Authorization methods:

  `viewAny(User $user): bool` — return true (list is scoped by Eloquent)

  `view(User $user, File $file): bool` — same logic as `download`

  `download(User $user, File $file): bool`:
  - If `$file->access_level === FileAccessLevel::AppPublic` → return true (any authenticated user)
  - If `$file->organization_id !== null` → check user is member of that org: `$user->organizations()->where('organizations.id', $file->organization_id)->exists()`
  - If `$file->organization_id === null` → check user is uploader: `$file->uploaded_by_user_id === $user->id`

  `delete(User $user, File $file): bool`:
  - User is the uploader: `$file->uploaded_by_user_id === $user->id`

  `forceDelete(User $user, File $file): bool` — return false

  Register the policy mapping in `app/Providers/AuthServiceProvider.php` if it exists, or rely on auto-discovery. Check which pattern the project uses — if there's no AuthServiceProvider (Laravel 12 may use auto-discovery), rely on auto-discovery by ensuring the policy follows the `App\Policies\{Model}Policy` naming convention. Since the model is `Wave\File`, auto-discovery won't find it — register explicitly in `bootstrap/app.php` or `AppServiceProvider` using `Gate::policy(File::class, FilePolicy::class)`.
  </action>
  <verify>Run `php artisan tinker --execute="echo Wave\File::factory()->make()->toJson();"` to confirm factory works. Run `php artisan tinker --execute="echo app(\Illuminate\Contracts\Auth\Access\Gate::class)->getPolicyFor(new \Wave\File) ? 'found' : 'missing';"` to confirm policy is registered.</verify>
  <done>FileFactory creates valid File instances with all states working. FilePolicy is registered and discoverable via Gate. All authorization methods return correct booleans for their scenarios.</done>

<task type="auto">
  <name>Task 1: Balance verification command</name>
  <files>app/Console/Commands/VerifyCreditBalances.php, routes/console.php</files>
  <action>
  **VerifyCreditBalances command** (`app/Console/Commands/VerifyCreditBalances.php`):
  Use `php artisan make:command VerifyCreditBalances --no-interaction` then customize.

  Signature: `credits:verify-balances`
  Description: `Verify that cached credit balances match ledger totals`

  Options:
  - `--fix` — auto-correct any mismatches (update balance_cached to match SUM)

  Logic:
  1. Query all organizations that have credit transactions (join or subquery)
  2. For each, compare `balance_cached` with `CreditTransaction::where('organization_id', $org->id)->sum('amount')`
  3. If mismatch:
     - Log warning: `"Balance mismatch for org {$org->id}: cached={$org->balance_cached}, actual={$actual}"`
     - If `--fix` flag: update `balance_cached` to the correct value and log info
  4. Output summary: `"Verified {$count} organizations. {$mismatches} mismatches found. {$fixed} fixed."`
  5. Return 0 if no mismatches (or all fixed), 1 if unfixed mismatches remain

  Use a single query with GROUP BY for efficiency instead of N+1:
  ```php
  $actuals = CreditTransaction::query()
      ->selectRaw('organization_id, SUM(amount) as total')
      ->groupBy('organization_id')
      ->pluck('total', 'organization_id');
  ```

  Compare with Organization::whereIn($actuals->keys())->pluck('balance_cached', 'id').

  **Schedule** (`routes/console.php`):
  Add: `Schedule::command('credits:verify-balances')->dailyAt('03:00');`
  Place near existing scheduled commands (activity:clean, accounts:process-deletions).
  </action>
  <verify>Run `php artisan credits:verify-balances` — should output "Verified X organizations. 0 mismatches found." Test the --fix flag by manually setting a wrong balance_cached and running with --fix.</verify>
  <done>Verification command detects and optionally fixes balance mismatches. Scheduled daily at 03:00. Efficient query, not N+1.</done>
</task>

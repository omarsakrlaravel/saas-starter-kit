<objective>
Create the credit transaction ledger model, migration, events, configuration, and supporting database columns.

Purpose: Establish the data layer for the credits system. Every credit operation (grant, consume, refund, adjustment) is recorded as a ledger entry in `credit_transactions`. Organizations get a `balance_cached` column for fast balance reads, and plans get `credits_per_cycle` for subscription-included credits.

Output: CreditTransaction model, migration, factory, CreditType enum, 4 credit events, credits config file, and balance/cycle columns on existing tables.
</objective>

  Create 4 simple event classes. Each should be dispatchable and contain relevant data.

  `CreditsGranted`:
  - Properties: `Organization $organization`, `int $amount`, `int $balanceAfter`, `CreditTransaction $transaction`
  - Constructor with all properties promoted

  `CreditsConsumed`:
  - Properties: `Organization $organization`, `int $amount`, `int $balanceAfter`, `CreditTransaction $transaction`

  `CreditsLow`:
  - Properties: `Organization $organization`, `int $currentBalance`, `int $threshold`
